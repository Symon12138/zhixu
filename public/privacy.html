隐私说明（模板）

版本：初稿模板 · 更新日期：发布前由运营方填写

本页面是待法律审阅的模板，不构成合规认证或法律意见。运营方在正式发布前应当：由合格法律顾问按适用司法辖区（如《个人信息保护法》、GDPR 等当地要求）审阅并修改本页；核实与实际数据处理一致；填写运营主体名称与联系方式。以下内容描述当前技术实现的实际数据处理方式，但不豁免运营方的法律义务。

1. 我们处理哪些数据

  • 账号数据：注册邮箱、经加盐哈希后的密码（原文不可恢复）、会话标识（仅存哈希）、账号恢复码（仅存哈希）。
  • 学习数据：学习会话与对话、理解证据与误区记录、笔记、复习项、诊断记录、学习活动日期、非敏感的模型偏好设置。这些数据在服务器端按账号隔离保存，用于跨设备同步。
  • 个人模型/搜索密钥：仅在运营方启用 BYOK（自带 Key）且你登录后保存时处理。你填写的模型与搜索 API Key、主/备用供应商配置会以加密形式保存在服务端 user_credentials 表中，仅用于你本人后续的模型与搜索请求，不会用于其他账户；浏览器本机存储（localStorage / IndexedDB）不保存这些 Key。服务端使用 AES-256-GCM 加密，密钥材料单独存放在服务器的 credentials.key 文件；缺少该文件时已保存的 Key 无法解密。
  • 书架数据：登录状态下导入/上传的书籍原文件与浏览器提取的章节、段落文本保存在账号级服务端书架，用于跨设备恢复；单本原文件上限 30 MiB，每账户最多 100 本、原文件总量 500 MiB。阅读进度与已读标记仍保存在当前浏览器，不随账号同步。
  • 额度与审计记录：每用户每日的模型调用次数（chat/diagnostic/review）；审计日志（注册、登录、登出、恢复、账户删除等事件）只含事件、结果、随机用户 ID、脱敏摘要与邮箱哈希摘要，不含明文邮箱、密码、恢复码或对话正文。为登录限流与防止滥用，服务端会短时处理客户端 IP 的哈希，反向代理访问日志会记录客户端 IP；除安全与故障排查外不用于其他目的，并按运维保留策略清理。

2. 浏览器本机存储

部分学习数据会先保存在你的浏览器 localStorage（学习会话、笔记、复习项、活动日期）与 IndexedDB（书架原文件、提取正文、阅读进度的本机缓存）。清理浏览器站点数据会清除本机缓存；登录状态下，服务端账号书架保留书籍原文件与提取正文，可在另一设备按需重新下载并校验 SHA-256。阅读进度仍只在本机，无法由服务端恢复。切换账号使用相互隔离的本机书架库。

3. 模型供应商

当你使用 AI 领学、诊断或复习补讲时，服务端会把当前对话内容、所附学习材料和相关学习状态发送给你所选择或运营方配置的模型供应商（Google Gemini 或 OpenAI 兼容服务）以生成回复。这些请求受供应商自身隐私政策约束，运营方不控制供应商对输入数据的使用与保留。请勿输入你不愿意第三方处理的敏感内容。若运营方启用 BYOK 且你已登录并保存了个人模型 Key，该 Key 会加密保存在服务端 user_credentials 表中，用于你之后发起的模型请求；登录状态下的模型请求只使用当前账户保存的个人 Key，未配置时会被明确拒绝，不会回退到服务端共享 Key。该 Key 不会写入审计日志，也不会提供给其他账户。

当你使用“自动联网搜索”时，服务端会把搜索查询发送给配置的搜索供应商（如 You.com、Tavily、Brave、Exa、Firecrawl、DeepSeek 或自建 SearXNG）；若你登录后保存了个人搜索 API Key，它同样加密保存在服务端 user_credentials 表中，用于你之后发起的搜索请求，不会用于其他用户，也不会写入日志；在启用 BYOK 的部署中，登录状态下的联网搜索只使用当前账户保存的个人搜索 Key，未配置时会被明确拒绝。数据库备份会包含加密后的凭据与配套的 credentials.key（见第 4 节）。当你使用“添加网页资料/逐字核验”时，服务端会向目标网页发起请求。目标网站或搜索供应商可能看到服务器 IP、查询和请求时间。搜索摘要、抓取到的网页正文、网址、抓取时间及可选的逐字命中引文会随学习资料发送给所选模型，并可能保存在本机学习记录或账号工作区中。请勿添加带登录令牌、个人隐私或不愿第三方处理的网址。联网结果只表示“有来源/搜索摘要”，不代表网页内容正确、完整或最新；运营方仍可能通过环境变量限制允许抓取的域名。

4. 服务端保存

登录用户的学习数据保存在部署方控制的单一服务器上的 SQLite 数据库中。数据按账号隔离；服务器不向第三方出售数据，不将对话正文写入访问日志。数据存储与备份的安全程度取决于部署方的运维措施。

启用 BYOK 时，个人模型/搜索配置与 API Key 以 AES-256-GCM 加密后保存在同一数据库的 user_credentials 表中，密文绑定账户 ID，不同账户的密文不能互相替换。加密所需的密钥材料单独存放在服务器数据目录的 credentials.key 文件（权限受限），不在数据库中。两者必须配套：只取得数据库无法解密 Key；credentials.key 缺失或与既有密文不匹配时，服务端会拒绝继续写入并提示从完整备份恢复。

5. 账号与数据删除

  • 你可以在登录状态下删除账号（需密码确认）。删除会级联移除服务端的全部学习数据、会话、恢复码、额度记录、加密保存的个人模型/搜索凭据（user_credentials 行）以及该账号的云端书目和原文件。
  • 删除账号不会删除服务器上的 credentials.key 文件：它是全站共用的密钥材料，其他账户的密文仍依赖它。你的个人凭据行会随账号删除，当前数据库中不再保留你的加密 Key。
  • 你可以只删除个人模型/搜索配置而不删除账号，此时对应的 user_credentials 行会被移除。
  • 删除前建议先导出学习数据备份。删除操作不可恢复。
  • 数据库备份会同时包含加密后的凭据行与配套的 credentials.key，以便恢复后仍能解密；这意味着备份文件本身即可还原 Key，部署方必须把备份当作密钥材料保护。历史备份中可能仍包含你此前的数据，随备份保留策略过期；具体保留期限见部署方公示或运营政策。你在页面导出的 JSON 学习数据备份只包含非敏感设置，不包含个人模型/搜索 Key。

6. 恢复码

创建账户或重置密码时，服务器会生成一次性恢复码，并只在当次页面显示。登录后还可在账户设置中凭当前密码生成新的恢复码，旧码会立即失效。恢复码仅以哈希形式保存，服务器无法替你找回；请立即离线保存。使用恢复码重置密码后，旧恢复码失效，并会显示一串新的恢复码。

7. 非绝对事实与教学边界

AI 生成的讲解、诊断与复习内容可能存在事实错误；本服务不认证任何内容的真实性，教学流程检查通过不等于事实正确。重要事实（产品参数、法规时效、医学或法律信息等）请核对可靠来源。
